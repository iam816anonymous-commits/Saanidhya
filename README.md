## Website

This repository contains the single-page Saanidhya website. The homepage is `index.html` and is built with plain HTML, CSS and JavaScript. It is responsive and does not require a build step or backend.

## Services presented

- Companionship and conversation
- Walks and outdoor activities
- Hospital and appointment accompaniment
- Everyday errands
- Family updates and wellbeing check-ins (with the senior's consent)
- Special visits and activities

Saanidhya is presented as a companionship and everyday-assistance service, not a medical, nursing or emergency-care provider.

## Enquiry form

The form asks for a visitor's name, contact number and requested service. On submission, it opens WhatsApp with a pre-filled enquiry addressed to **+91 79932 90629**. The visitor must review and press Send in WhatsApp. The website does not store form submissions.

## Run locally

Open `index.html` in a modern browser. No package installation is needed.

## Deploy with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Save. GitHub Pages will publish the site at:

   `https://iam816anonymous-commits.github.io/Saanidhya/`

## Before public launch

- Confirm service area, availability and pricing directly with the founder.
- Test the enquiry flow on a phone with WhatsApp installed.
- Replace or approve the externally hosted demonstration photographs.
- Publish a privacy notice and clear service terms before collecting real enquiries.
- Do not claim medical qualifications, background checks, insurance or emergency coverage unless these are actually in place.
